## Coverage measurement excludes `src/graphql/generated.go`

**AI.md PART 26/28 canonical form:** both the `test` Makefile target and
`ci.yml`'s "Enforce coverage threshold" step compute coverage from the raw,
unfiltered `coverage.out` produced by `go test -cover ./...`.

**Override:** this project's coverage gate (both `ci.yml` and `make test`)
excludes `src/graphql/generated.go` before computing the percentage
(`grep -v '/graphql/generated\.go:' coverage.out > coverage.filtered.out`,
then `go tool cover -func=coverage.filtered.out`).

**Reason:** `src/graphql/generated.go` is gqlgen's mechanically-generated
dispatch/marshalling file (`// Code generated by github.com/99designs/gqlgen,
DO NOT EDIT.`) — it is never hand-edited and contains no business logic to
test, but its sheer size (dispatch tables for every resolver/type) dominates
the package's statement count enough to make the real, hand-written
resolver/helper coverage in the same package unmeasurable through the raw
total. Filtering it out is the standard practice for generated-code coverage
noise and does not weaken the intent of the ≥60% gate — it makes the gate
measure code a human actually wrote and can improve.

**Compliance requirement:** `make test` (local) and `ci.yml` (CI) MUST use
the identical filter so the coverage percentage a developer sees locally
matches what CI enforces — see TODO.AI.md item 16.
